# ΔMARS Lab website

Official lab website for ΔMARS Lab, Oakland University.

This repository contains the static HTML, CSS, JavaScript, and assets prepared for GitHub Pages. Commits to `main` deploy automatically to https://dmarslab.github.io/ through the GitHub Pages workflow.

The website entry point is `index.html`. Project pages are `project-*.html`. Contact links use email; no server-side code is required.

Bootstrap and Bootstrap Icons retain their embedded MIT license notices. Research media are credited beside their publication entries; their original licenses and source attribution apply.
